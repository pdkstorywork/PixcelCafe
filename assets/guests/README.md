# 손님 에셋 위치표

손님 그림은 두 곳에 나뉘어 있다. 새 손님은 아래 규칙대로 추가한다.

| 구분 | 위치 | 크기 | 비고 |
|---|---|---|---|
| 일반 손님 (동물: cat/dog/rabbit/bear/hamster/mouse/fox) | `assets/pixelcafe-atlas*.png` (`animal/*`) | 아틀라스 | 1x/2x/3x 각각 원화 |
| 기본 희귀 손님 (chiikawa, usagi, hachiware, kitty, melody, kuromi, cinna, purin, ganadi, loopy, ryan, apeach, pororo, pikachu, chunsik) | `assets/pixelcafe-atlas*.png` (`rare/*`) | 아틀라스 | 전설 3종 = hachiware, chiikawa, usagi |
| 가족 손님 외형 1~9 | `assets/pixelcafe-atlas*.png` (`family/variant01~09`) | 아틀라스 | |
| 가족별 개별 원화 6종 | `assets/guests/family_<id>.png` 및 `@2x`, `@3x` | 24×34 / 48×68 / 72×102 | `collection.py`의 `FAMILY_ASSETS`가 아틀라스보다 우선 |
| 추가 희귀 손님 (totoro, stitch, pooh, rilakkuma, snoopy, kaonashi, kumamon, gudetama) | `assets/guests/<id>.png` | 22x26 | 큰 이미지는 축소됨 |
| 가족 손님 계절·기념일 오버레이 | `assets/guests/family_<계절·기념일>.png` | 24x34 투명 | 계절·기념일: spring summer autumn winter newyear valentine halloween christmas |
| 외형별 오버레이 (선택) | `assets/guests/family_<1-9>_<계절·기념일>.png` | 24x34 투명 | 있으면 위 파일보다 우선 |
| 이름 있는 가족 손님 (도야니, 셔니) | `assets/guests/named_<이름>.png` | 24x34 | `collection.py`의 `NAMED_FAMILY`에 등록 |

## 새 손님 추가 규칙
- 추가 희귀 손님: `<id>.png`를 이 폴더에 넣고, `collection.py`의 `NEW_RARE`(이름), `PLACEHOLDER`(임시 색), `GUEST_HINT`(힌트 문구)에 id를 추가한다.
- 이름 있는 가족 손님: `named_<이름>.png`를 넣고 `NAMED_FAMILY`에 `'이름': (외형번호, 'named_이름.png')`을 추가한다.
- 아틀라스 손님은 아틀라스와 `manifest.json`을 다시 만들어야 하므로, 신규는 가급적 이 폴더에 개별 PNG로 추가한다.
- 파일이 없으면 코드가 그린 임시 그림이 나오지만, 이름 있는 가족 손님은 파일이 없으면 오류가 난다.

제작: 내장 imagegen으로 가족마다 개별 생성 및 편집. 공통 프롬프트: 기존 PixelCafe 가족 손님을 참고한 손도트 픽셀 아트, 정면 전신 치비, 작은 갈색 점눈, 따뜻한 갈색 외곽선, 저채도 파스텔 19색 이내, 좌상단 광원과 3단 명암, 투명 배경, 글자·바닥·그림자 없음. 가족별 머리·의상은 위 디자인을 적용했다. 기존 외형 번호·저장 데이터는 유지하며, 계절 오버레이는 기존 방식으로 합성한다.

눈·외곽선 수정: 6가족 모두 원본 PNG를 내장 imagegen의 편집 대상으로 사용했다. 수정 프롬프트: 기존 머리·옷·포즈를 보존하고, 앞머리를 눈 위로 올려 눈과 머리 사이 피부색 여백 확보, 작은 진갈색 세로 점눈과 작은 미소, 머리·귀·의상·손·신발에 끊기지 않는 어두운 갈색 외곽선, 평면 색면과 계단형 도트 경계, 흐림·그라데이션·안티앨리어싱 금지. 진예·미예·도경의 두 눈이 앞머리에 가려지지 않도록 특히 강조했다. 원화를 최근접 보간으로 72×102에 정규화하고 48×68 및 24×34로 축소해 색 혼합을 피했다. 모든 결과는 19색 이내·이진 알파이며, 1x/3x를 확대해 눈과 외곽선을 비교 확인했다.

추가 보정: 지현은 내장 imagegen으로 열린 앞머리와 진갈색 세로 점눈을 편집하고, 1x 양쪽 눈이 각각 연속된 2개 어두운 픽셀로 남는 축소 격자를 사용했다. 미예는 다리의 점선·잡색을 없애고, 축소 후에도 남는 두께의 진갈색 연속 외곽선 및 단색 신발로 편집했다. 지영은 반바지 아래 살색 폭을 줄이고 다리 사이를 비웠다. 수정 프롬프트는 기존 외형을 유지하며 각 결함 부위만 수정하고, 투명 배경·제한 팔레트·안티앨리어싱 금지를 유지하는 조건이었다.

**발 위치 고정 규칙:** 도야니·셔니의 기존 보정과 동일하게 1x/2x/3x의 알파 bbox 하단(끝 좌표 제외)은 반드시 **32 / 64 / 96**이다. 즉 1x의 마지막 불투명 행은 y=31이며 y=32~33은 투명하다. 6가족 전체를 이 기준에 맞췄고, 도경·배지·진예는 기존 그림을 각각 1·2·3px 위로 옮기기만 했다. 도야니·셔니 파일은 수정하지 않았다. 원화 재반영 시 `(3,3)`에 66×96을 배치하면 발 위치가 다시 내려가므로 `(3,0)`을 사용한다. `test_game_data.py`에 8종 × 3해상도 발 위치 검사와 지현의 1x 두 눈 검사를 추가했다.

미예 눈 복원: 내장 imagegen 편집 프롬프트는 기존 외형의 눈만 진갈색 세로 점눈으로 복원하고 나머지를 보존하는 조건이었다. 생성 결과 전체를 다시 축소해 덮어쓰지 않고 눈 부분만 추출·배치했다. 1x는 `(9,11)`, `(14,11)`에 각각 1×2px, 2x는 `(18,20)`, `(28,20)`에 각각 2×4px, 3x는 `(27,30)`, `(42,30)`에 각각 3×6px이다. 변경 픽셀 수는 각각 4/16/36개이며, 눈 이외 픽셀과 다른 손님 PNG가 동일함을 검사했다. 외형 6의 세 해상도와 계절 오버레이 8종에서도 양쪽 눈 픽셀이 불투명한 진갈색으로 남는 회귀 검사를 추가했다.
