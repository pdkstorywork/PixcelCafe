# PixelCafe

픽셀 카페를 키우는 게임입니다. Windows용입니다.

## 플레이 방법

1. [Releases](../../releases/latest)에서 `PixelCafe.exe`를 내려받습니다.
2. 쓰기 가능한 폴더(바탕화면, 문서 등)에 두고 실행합니다.
3. 새 버전이 나오면 실행할 때 업데이트 안내가 뜹니다.

게임 저장 데이터는 `%APPDATA%/PixelCafe`에 저장되며 업데이트해도 유지됩니다.

## 수집과 성장 속도

- 하루 8~10시간 켜 두는 플레이를 기준으로, 약 200~300일 동안 수집하도록 조정했습니다.
  레시피는 판매·수익·가구·손님 조건과 누적 영업 시간을 함께 확인하며, 마지막 빵은
  2,000시간 이후 해금됩니다. 종료·절전 시간은 영업 시간으로 계산하지 않습니다.
- 첫 가구 두 개는 250G·500G를 유지하고, 나머지 가구·인테리어·의상·직원·진열대는
  기존 대비 약 3배 가격입니다(기본 품목 최대 300만G). 빵 레벨과 수집 보너스의
  수익 증가 폭을 줄였으며, 직원·동료의 1→10레벨 성장은 영업 360시간이 필요합니다.
- 가족 손님은 현재 계절·기념일의 미발견 인물에 중복 방지를 적용합니다.
  희귀·전설·가족 등장률과 특별빵 발생률은 유지합니다.
- 실제 달력에 맞춘 계절·기념일은 그대로입니다. 해당 날짜를 놓치거나 시작 시점이
  늦으면 연간 도감 전체 완성은 300일을 넘길 수 있습니다.
- 기존에 얻은 빵·도감·가구·레벨은 유지합니다. 새 가격·보너스는 기존 카페에도 적용합니다.

검증: `python -m unittest test_balance -v`.
`python test_balance.py --simulate 8` 또는 `--simulate 10`으로 300일 예측을 실행합니다.
시간당 방문 100명(실제 후반 루프 측정 101명), 2026년 3월 1일 시작,
고정 난수 1729, 동료 영입 후 저렴한 품목부터 구매하는 조건에서 다음 결과를 얻었습니다.
이동·착석은 생략하고 실제 주문·계산·수집·상점 코드를 사용한 예측이며,
구매 순서·방문량·확률·시작 계절에 따라 실제 기간은 달라집니다.
